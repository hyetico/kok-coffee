| 항목 | 값 |

## 값 정할 때 참고 — 기준과 관례
값을 새로 정할 때 보는 장. ① 기준(WCAG 2.2 AA)은 반드시 지키고, ② 관례는 이 프로젝트에서 아래처럼 정했다.

| 항목 | ① 기준 | 이 프로젝트 값 |
|---|---|---|
| 글자 대비 | 본문 4.5:1 · 큰 글자 3:1 | 보조 글자 `muted` 5.9:1. `subtle`은 3.8:1이라 글자에 쓰지 않음 |
| 테두리 대비 | 버튼 테두리 · 입력창 선 3:1 | 입력 · 칩 · 옵션 · 정렬 · 보조 버튼 테두리 `line-control`(3.8:1). 구분선은 장식이라 `line` |
| 누르는 영역 | 최소 24 × 24 | 기본 44 · 작은 버튼 36. 맛 지도 점 · 메뉴 · 경로 링크는 보이는 크기 그대로, 누르는 칸만 24 이상 |
| 입력창 글자 | 16 이상 (아이폰 자동 확대 방지) | 16 · 검색 레이어 18 |
| 토스트 | 읽기 전에 사라지지 않음 · `role="status"` | 4초 · 링크나 되돌리기가 있으면 6초 · 마우스/초점이 올라가면 멈춤 |
| 키보드 · 초점 | 초점이 보이고 가려지지 않음 | `:focus-visible` 2px. 고정 헤더 · 도구 줄 아래로 가리지 않게 `scroll-padding-top` |
| 움직임 | `prefers-reduced-motion`이면 멈춤 | 모든 전환 · 스켈레톤 빛 멈춤 |
| 확대 · 좁은 화면 | 폭 320에서 가로 스크롤 없음 | 확인함. 높이 560 이하면 고정 영역 해제 |
| 중복 링크 | — | 상품 카드의 사진 링크는 `aria-hidden` + `tabindex="-1"` (상품명 링크와 같은 곳) |
| 버튼 높이 | — | 큼 52 · 보통 44 · 작음 36 |
| 간격 단위 | — | 4의 배수: 4 · 8 · 12 · 16 · 20 · 24 · 32 · 40 · 48 · 64 |
| 겹침 순서 | — | 헤더 30 < 로스터리 패널 35 < 검색 패널 40 < 모달 60 < 검색 레이어 80 (토스트는 20이지만 열린 레이어가 없을 때만 뜸) |

  --color-hero: #E6EDE8;
  --color-footer-bg: #F7F9F8;
  --color-ink: #17201B;

## 버튼
`<Button kind size icon>` 하나로 만든다.

| 컴포넌트 | 규칙 | 모양 |
|---|---|---|
| primary | 한 화면에 하나. 담기 · 바로 구매 · 주문하기. 마우스 올림 `primary-hover`, 누름 `primary-press` | 견본: btn-primary |
| secondary | 흰 바탕 + `line-control` 테두리, 올림 시 테두리 `ink`. 자세히 보기 · 쇼핑 계속하기 · 카드의 담기 | 견본: btn-secondary |
| ghost | `surface` 바탕. 로스터리 전체 보기 | 견본: btn-ghost |
| text | 밑줄 없는 글자 버튼 `muted`, 좌우 8. 올림 시 `surface` 바탕 + `ink` 글자. 초기화 · 삭제 · 처음으로 | 견본: btn-text |
| 더보기 링크 (`<MoreLink>`) | 섹션 오른쪽 「전체 보기」 · 「로스터리 16곳 보기」. 14 600 `ink` + 오른쪽 화살표 16, 누르는 칸 44. 올림 시 `primary` + 화살표 2px 이동. 밑줄 없음. 글자 끝선이 섹션 오른쪽 끝선과 맞게 화살표 여백 보정 | 견본: more |
| 밑줄 | 버튼 · 링크 버튼에는 밑줄을 쓰지 않는다. 밑줄은 내비게이션(헤더 메뉴 현재 표시 · 푸터 링크 올림)에만 | — |
| 크기 | 큼 52 / 16 · 보통 44 / 16 · 작음 36 / 14 · 아이콘 버튼 44 × 44 | 견본: btn-sizes |
| 상태 | 비활성: `line-soft` 바탕 + 회색 글자. 포커스: `outline 2px primary, offset 2px` | 견본: btn-states |
| 이름 | 동사로 짧게, 같은 동작은 같은 낱말("담기") | — |
| 버튼 묶음 (`<ButtonPair>`) | primary와 secondary를 나란히 둘 때. 주 동작(primary)이 먼저. 두 버튼 **너비가 같다**(긴 쪽에 맞춤), 간격 12. 묶음 안 secondary는 테두리 · 글자를 `primary`로해서 채운 버튼과 무게를 맞춘다. 올림 시 `option-on` 바탕. 모바일(≤640)은 한 줄 꽉 채워 반씩, 374 이하는 위아래로. 메인 첫 화면 「30초 취향 테스트」 + 「모든 원두 보기」 | 견본: btn-pair |

## 입력
| 컴포넌트 | 규칙 | 모양 |
|---|---|---|
| 기본 | 44, `line-control` 테두리, 글자 16, 안내 글 `muted`. 라벨은 화면에 보이거나(폼) 검색창은 `aria-label` | 견본: input |
| 페이지 안 검색 (`<SearchInput>`) | 목록 도구 줄 · 로스터리 목록이 **같은 컴포넌트**: 왼쪽 돋보기 18(`muted`, 왼쪽 12), 입력 안쪽 왼 40 · 오른 44, 모서리 8, 값이 있으면 지우기 버튼. 폭만 자리마다 다름(목록 전체 폭, 로스터리 360) | 견본: input-clear |
| 포커스 | 테두리 `primary` + 3px 옅은 그린 링 | 견본: input-focus |
| 지우기 버튼 | 입력값이 있을 때만, 오른쪽 10px, 24px 원형, 이름 "검색어 지우기", 누르면 입력창으로 초점. 브라우저 기본 X는 숨김 | 견본: input-clear |
| 정렬 드롭다운 | 36 버튼(현재 값 + 화살표). 열리면 테두리 `ink`, 화살표 180°. 항목 40, 고른 항목은 `primary` + 체크. "정렬" 라벨은 `aria-label`로만 | 견본: select |
| 수량 | 테두리 박스 안 − · 숫자 · + (각 44 — 상세 · 장바구니 같음), 모서리 8, 1~20. 숫자 입력 ▲▼ 쓰지 않음 | 견본: qty |
| 라벨 · 필수 | 입력창 위 보이는 라벨 14 굵게, 아래 간격 8. 필수는 라벨 끝 `*`(`error` 색, 읽지 않음) + `aria-required`. 섹션 위에 「* 표시는 꼭 입력해 주세요」 | 견본: field |
| 오류 | 테두리 `error`(#B8321D), 포커스 링도 붉게. 칸 바로 아래 6px에 아이콘 16 + 글 14 `error`, `aria-invalid` · `aria-describedby`로 연결. 결제 시 검사하고 첫 오류 칸으로 포커스, 고치면 그 칸의 오류만 사라짐 | 견본: field-error |
| 휴대폰 | `type=tel` · `inputmode=numeric`, 숫자만 받아 010-0000-0000으로 하이픈 자동 | — |
| Textarea | 해당 없음 | — |
