## 0. 문서 안내
- 공용 틀의 **구조 문서**. 4장은 만들 컴포넌트 파일 목록이고, 각 컴포넌트의 모양 · 규격 · 토큰은 [05 Components](05-Components.md) (프로토타입 클래스 → 컴포넌트 대응은 05 「지금 코드 대체표」).

## 1. 기술 스택
| 항목 | 선택 | 이유 |
|---|---|---|
| 프레임워크 | Next.js 최신 버전 (App Router) | 페이지별 정적 생성, `next/image` |
| 언어 | TypeScript | 상품·장바구니 타입 안정성 |
| 스타일 | Tailwind CSS (최신 버전) | 디자인 토큰을 `@theme`에 한 번에 정의, 라이브러리 혼용 해소 |
| 상태 | Zustand + `persist` | 장바구니를 localStorage에 저장, 코드가 짧음 |
| 서체 | Pretendard (`next/font/local`) | 한글 가독성, 레이아웃 흔들림 방지 |
| 배포 | Vercel | Next.js 기본 지원 |

## 3. 타입
```ts
export type Size = '200g' | '500g' | '1kg'
export type Grind = 'whole' | 'coffee-maker' | 'espresso' | 'french-press' | 'hand-drip' | 'moka-pot'

export interface Product {
  id: string                 // 'p1'…'p21' · 브랜드 전용 'c2'…'c4'
  title: string
  roastery: string           // 로스터리 이름 (화면 표시)
  roasteryId: string | null  // 「함께하는 로스터리」 목록에 있으면 id, 없으면 null
  roasteryLogo: string
  type: 'blend' | 'single'
  decaf: boolean
  notes: string              // 'A & B' — 화면에 그대로 표시, 필터는 & 로 나눠 비교
  price: number              // 200g 기준 (500g +4,600 · 1kg +11,000)
  image: string              // /images/products/<id>.webp
  mapPosition: { x: number; y: number } | null // 맛 지도 좌표: x 고소한(0)→화사한(100), y 묵직한(0)→가벼운(100)
  brandOnly?: boolean        // true면 목록 · 지도 · 검색에 안 나오고 브랜드 페이지에만 (c2–c4)
  source?: string            // 원본 자료 위치 (기록용)
}

export interface CartItem {
  key: string            // productId + 옵션 조합
  productId: string
  size: Size
  grind: Grind
  qty: number
  checked: boolean
}
```

## 7. 참고: iCloud 폴더
프로젝트는 데스크탑(iCloud 동기화 폴더) 안에 그대로 둔다. 옮기지 않는다.
`node_modules` · `.next`만 **그 자리에 둔 채** iCloud 업로드에서 뺀다 — 맥의 "iCloud 제외" 표시(`xattr`)를 붙인다.

- 심볼릭 링크(`node_modules.nosync` + `ln -s`)는 쓰지 않는다. Next 16 Turbopack이 링크를 따라가지 못해 `@tailwindcss/turbopack`을 못 찾는 오류가 난다.
- `package.json`에 아래를 넣어 두면 `npm install` · `npm run dev` · `npm run build` 때 자동으로 붙는다. 맥이 아닌 곳(Vercel)에서는 조용히 넘어간다.

```json
"scripts": {
  "postinstall": "xattr -w 'com.apple.fileprovider.ignore#P' 1 node_modules 2>/dev/null || true",
  "predev": "mkdir -p .next && xattr -w 'com.apple.fileprovider.ignore#P' 1 .next 2>/dev/null || true",
  "prebuild": "mkdir -p .next && xattr -w 'com.apple.fileprovider.ignore#P' 1 .next 2>/dev/null || true"
}
```
- 확인: `xattr -l node_modules` 에 `com.apple.fileprovider.ignore#P` 가 보이면 됨.

## 8. 이번 보완으로 추가된 구조
- `app/not-found.tsx`: 404 페이지. 푸터 링크(공지사항, 약관 등)도 여기로 연결
- `app/coffee/loading.tsx`, `app/coffee/error.tsx`: 목록 스켈레톤과 오류 화면
- `store/cart.ts`(Zustand persist): `items: { productId, size, grind, qty, checked }[]`, `add`, `setQty`, `remove`, `restore`. 배지는 `items.length`
- `store/search.ts`(persist): `recent: string[]`(최대 6개), `addRecent`, `removeRecent`, `clearRecent`
- 상품 상세 `/coffee/[id]`: `detailImages?`, `tasteProfile?`가 있는 상품만 해당 영역 표시. 없으면 상품 정보 표
- 로스터리 `/roasteries/[id]`: `store?`(사진, 수상 경력, 위치, 인스타그램)가 있는 곳만 해당 영역 표시. 원두가 없으면 빈 상태
- `hooks/useHideOnScroll.ts`: 목록 페이지에서 스크롤 방향으로 헤더 숨김/표시, 타이틀을 지났는지(`past`)도 함께 돌려줘 `ListToolbar`가 "페이지 이름 · n개"를 보여줌. 헤더 안 `focusin`이면 숨김 해제. `data-header-hidden`을 `<html>`에 붙이고 CSS로 헤더·도구 줄·필터 위치를 바꿈
- 임시 콘텐츠: `lib/temp-content.ts`에서 맛 노트로 맛 프로필·로스팅·소개 문장·추천 추출법을 만든다. 실제 자료가 들어오면 상품 데이터의 값이 우선

## 9. 브라우저 기본 UI 정리 (전역 CSS)
- 검색 입력의 기본 X(`::-webkit-search-cancel-button`)와 장식 숨김 → `ClearButton`으로 대체
- 숫자 입력의 ▲▼ 숨김(현재 화면엔 숫자 입력 없음, 수량은 −/+ 버튼)
- 자동완성 배경색을 입력창 배경과 같게(`-webkit-autofill` + inset box-shadow)
- 포커스 테두리는 `:focus-visible`에서만(마우스 클릭 시 테두리 없음, 키보드 이동 시 2px `primary`)
- 모바일 탭 번쩍임 제거(`-webkit-tap-highlight-color: transparent`)
- `<details>` 기본 삼각형 표시 숨김
- 검색 레이어·필터 사이드바·필터 시트·추출법 표의 스크롤바는 6px 얇은 막대(색 `line` 계열)
- select 기본 화살표: 서비스 화면에는 select가 없음. 프로토타입 도구 막대의 화면 선택만 직접 그린 화살표로 교체
- 스크롤바로 화면이 밀리지 않게 실제 사이트에서는 `@media (hover: hover) and (pointer: fine) { html { scrollbar-gutter: stable } }`. 프로토타입 보드에는 넣지 않는다(보드 오른쪽에 빈 줄이 생겨 폭이 바뀜).
