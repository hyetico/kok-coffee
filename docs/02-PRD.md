## 1. 한 줄 요약
2022년에 HTML/jQuery와 React로 두 번 만든 커피 큐레이션 쇼핑몰 **코케**를 Next.js로 다시 만든다. 리뉴얼하며 브랜드 이름을 **콕커피**(로고 「콕˙ KOK」)로 바꾼다 — 맛 지도에서 내 자리를 「콕」 찍는 서비스라는 뜻. 요즘 쇼핑몰 문법(딥 그린 포인트 디자인, 맛 지도), 반응형, 웹 접근성, 정리된 데이터 구조로 리뉴얼해 **같은 서비스를 세 번 만들며 성장한 과정**을 보여준다.

## 3. 범위

### 이번에 만드는 것 (MVP)
| 페이지 | 경로 | 핵심 기능 |
|---|---|---|
| 메인 | `/` | **맛 지도**(원두 17종을 맛 축 위에 표시, 종류 필터, 선택한 원두 바로 담기), 취향 테스트·모든 원두 링크, 많이 담는 원두(맛 노트 탭), 새로 들어온 원두, 함께하는 로스터리, 브랜드 배너 |
| 목록 | `/coffee` | 필터 맨 위 「종류」(전체/블렌드/싱글오리진, **모든커피에서만** 표시, 상단 메뉴와 같은 항목). 디카페인은 종류가 아니라 속성이라 탭에 넣지 않고 필터의 "카페인: 디카페인" 칩으로 고름(세 목록 모두 동일). 목록 위 도구 줄(한 줄: 개수 · 검색창 · 목록/지도 · 정렬, 모바일은 검색창이 위 줄)은 헤더 아래에 고정, 아래로 스크롤하면 헤더가 숨고 위로 스크롤하면 다시 나타남(도구 줄은 맨 위로 따라 올라감). 타이틀은 스크롤과 함께 올라가고, 타이틀을 지나면 도구 줄의 "총 n개"가 "모든커피 · n개"로 바뀌어 현재 위치를 계속 보여줌(모바일은 "n개"). 스크롤한 상태에서 필터 · 정렬 · 검색 · 보기를 바꾸면 목록 맨 위가 도구 줄 바로 아래에 오도록 올려 줌. 상품이 적어도 도구 줄은 목록 영역 끝(푸터 직전)까지 고정. 접근성: Tab으로 이동할 때 포커스가 고정 영역에 가려지지 않게 scroll-padding, 숨은 헤더에 포커스가 들어오면 헤더 다시 표시, 화면 높이 560px 이하(확대 등)에서는 헤더·도구 줄·필터 고정 해제, 왼쪽 필터는 헤더 아래에 고정하되 화면보다 길면 필터 안에서만 스크롤, **가격대 필터**(1만 원 미만 · 1만 ~ 1만 5천 원 · 1만 5천 ~ 2만 원 · 2만 원 이상, 여러 개 고르면 그중 하나에 맞으면 표시 — 기존 kokewep 「가격대」 계승), 맛과 향 다중 필터, 적용한 조건 칩(개별·전체 해제), 정렬 드롭다운(추천/낮은 가격/높은 가격), **목록/지도 보기 전환**, 카드 아래 담기 버튼, 결과 0개 상태, 들어올 때 약 1초 스켈레톤, 1023px 이하에서는 "필터" 버튼 → 아래에서 올라오는 필터 시트(고른 개수 배지, "상품 n개 보기"). 검색은 헤더 검색창을 그대로 쓰고 입력하는 즉시 결과에 반영 |
| 싱글오리진 · 블렌드 | `/coffee?type=single`, `/coffee?type=blend` | 해당 종류만 보여주는 목록. 종류 필터 없음, 맛과 향 필터·검색·정렬은 동일 |
| 검색 결과 | `/coffee?q=케냐` | 모든커피 목록에 검색어 적용. 헤더 검색 레이어에서 Enter, 추천·최근 검색어, "모두 보기"를 누르면 이 화면으로 이동하고 목록 검색창에 같은 검색어가 들어감 |
| 상세 | `/coffee/[id]` | 이미지 갤러리, 원두 용량·분쇄 선택, 수량, 합계 계산, 맛 프로필(텍스트), 장바구니 담기 알림, 상품 정보/배송·교환 탭, 같은 로스터리 원두 |
| 장바구니 | `/cart` | 전체·개별 선택, 수량 변경, 삭제(되돌리기), 배송비(3만원 이상 무료), 무료배송까지 남은 금액, 「n개 상품 주문하기」 → 고른 상품으로 주문서, 빈 장바구니 상태 |
| 주문서 | `/checkout` (상세 「바로 구매」도 이 상품 하나만 골라 바로 이동) | 주문 상품 요약, 받는 분(이름 · 휴대폰 자동 하이픈 · 주소 · 상세 주소 직접 입력), 결제 수단(카드 · 계좌이체 · 간편결제 중 하나), 약관 동의(전체 + 필수 2), 결제 금액 고정 요약. 「결제하기」에서 검사 → 칸 아래 오류 글 + 첫 오류 칸으로 포커스, 통과하면 「결제 중…」 1.5초 → 주문 완료. 들어올 때 스켈레톤, 고른 상품이 없으면 빈 상태. 실제 결제는 하지 않음 |
| 주문 완료 | `/order/complete` | 완료 표시, 가상 주문 번호, 받는 분 · 배송지 · 결제 수단 · 금액, 주문 상품, 「쇼핑 계속하기」 · 「홈으로」. 주문한 상품은 장바구니에서 빠짐 |
| 취향 테스트 | `/taste-test` | 시작 화면, 질문 5개, 진행률, 결과(추천 원두 3개 + 분쇄 안내) |
| 로스터리 | `/roasteries` | 로스터리 16곳 목록, 이름 검색 |
| 404 | `not-found` | 없는 주소와 준비 중인 페이지 안내, 홈·모든커피로 가는 버튼 |
| 브랜드 | `/roasteries/[id]` | 매장 사진, 수상 경력, 위치·인스타그램, 해당 로스터리 원두와 바로 담기 |

- 관리자 페이지, 서버/DB (상품 데이터는 JSON)

## 4. 기능 요구사항

### 공통
- 헤더: **홈**은 2줄(1줄 로고 · 가운데 검색창 · "장바구니 n" / 2줄 카테고리 메뉴). **홈 밖**(웹 1024px 이상)은 1줄 — 로고 · 가운데 메뉴(홈, 모든커피, 싱글오리진, 블렌드, 로스터리, 취향테스트) · 돋보기와 장바구니. 태블릿 · 모바일은 어디서나 2줄(메뉴 가로 스크롤). 장바구니 배지는 실제 담긴 개수
- 홈 헤더 스크롤(웹 1024px 이상): 140px 넘게 아래로 스크롤하면 홈 밖과 같은 1줄 헤더(로고 · 가운데 메뉴 · 돋보기 · 장바구니)로 바뀌고, 위로 스크롤하면 원래 2줄 헤더로 돌아온다. 바뀔 때 본문이 튀지 않게 줄어든 높이(60px)만큼 헤더 아래 여백으로 채운다
- 헤더 — 태블릿 · 모바일(1023px 이하): 1줄(로고 · 돋보기 · 장바구니 · ☰ 맨 오른쪽). 메뉴는 ☰를 누르면 오른쪽에서 나오는 드로어. 헤더는 모든 기기에서 위에 고정.
- 헤더 검색: **홈**에서만 헤더 가운데에 480px 입력창 모양 검색 트리거를 두고, 다른 페이지와 1023px 이하에서는 장바구니 옆 돋보기 버튼만 둔다. 누르면 헤더 위를 덮는 **검색 레이어**가 열리고 입력 칸에 바로 포커스. 레이어 왼쪽은 최근·추천 검색어, 오른쪽은 많이 찾는 원두 또는 입력 중 미리 보기 결과(최대 5개)와 "검색 결과 n개 모두 보기". X 닫기 버튼(입력 칸과 같은 52px)·ESC·바깥 클릭으로 닫힘. 입력 중에는 입력 칸 안 지우기 버튼
- 본문 검색창은 목록의 도구 줄에만 둔다. 상세·장바구니 등 다른 페이지에는 본문 검색창 없이 헤더 트리거만 둔다
- 푸터: 고객센터(예시 번호 1588-0000, 운영 시간, 이메일), 지원 메뉴, 약관 링크, 예시 사업자 정보, 포트폴리오 고지문. 포트폴리오 안내는 첫 방문 모달 없이 **푸터 고지문 한 곳**에만 둔다
- 푸터 메뉴(공지사항, 자주 묻는 질문, 1:1 문의, 입점 문의, 회사 소개, 이용약관, 개인정보처리방침, 배송 · 교환 안내)는 만들 페이지가 없어 **링크 없는 글자**로 둔다. 모두 같은 굵기
- 최근 검색어: 검색 레이어 왼쪽 위에 최대 6개, 하나씩 지우기와 전체 삭제. localStorage에 저장
- 로스터리 메뉴: **홈(PC)** 에서만 헤더 아래 전체 폭으로 펼쳐지는 로스터리 16곳 메뉴(원본 kokewep의 브랜드 드롭다운 계승). 열리면 "로스터리" 메뉴도 현재 메뉴처럼 진하게 + 밑줄. 다른 페이지와 태블릿·모바일에서는 누르면 바로 로스터리 페이지로 이동
- 용어: 블렌드로 통일 (상품 고유 이름은 로스터리 표기 유지)
- 헤더는 웹 · 태블릿 · 모바일 모두 위에 고정 (목록에서는 아래로 스크롤하면 숨고, 위로 스크롤하면 다시 나옴)
- 누를 수 있는 곳 최소 36px(모바일 주요 버튼 44px 이상), 키보드 포커스 표시
- 버튼·칩·드롭다운·입력 등 UI는 05 Components의 규격 · 견본을 따름

### 목록 — 맛 지도 → 목록 (모든커피 · 싱글오리진 · 블렌드)
- 맨 위에 맛 지도, 그 아래 원두 목록. 기본 보기는 「지도 + 목록」, 도구 줄의 「목록만」으로 지도를 숨길 수 있다
- 필터는 왼쪽 체크 목록(흰 바탕): 종류(모든커피만, 라디오) · 카페인(디카페인만) · 가격 4구간 · 맛(산미 · 바디 슬라이더, 지도 구간과 같은 낮음 · 중간 · 높음 3칸) · 향 12개(처음 6개 + 「더 보기」). 묶음 안은 「또는」(향은 「그리고」), 묶음 사이는 「그리고」. 1023px 이하는 「필터」 버튼 → 아래 시트
- 필터 · 검색 결과는 지도와 목록에 함께 적용: 맞지 않는 점은 흐리게, 맛 슬라이더를 좁히면 그 범위를 지도에 구간 상자로 표시
- 「지도 + 목록」에서 지도는 목록을 고르는 도구: 점을 누르면 정보 창 없이 아래 목록이 「고른 원두 → 맛이 가까운 순」으로 바뀌고, 맛이 가장 가까운 3개에 점선 원. 같은 자리 원두는 숫자 점 하나로 묶고, 누르면 묶인 원두가 목록 맨 앞
- 목록 제목 「원두」 아래 한 줄에 「총 n개」(왼쪽) · 정렬(오른쪽). 정렬: 추천순 · 내 취향과 가까운 순(취향 테스트 후에만) · 낮은 가격순 · 높은 가격순
- 취향 테스트는 강요하지 않는다: 테스트 전에는 지도 안 뱃지 「내 취향은 어디쯤일까? 30초 테스트 →」(닫기 가능) 하나만. 테스트 후에는 지도에 「내 취향」 핀, 정렬 기본 「내 취향과 가까운 순」, 필터 맨 위 「내 취향」 박스와 「내 취향으로 거르기」 버튼(맛 슬라이더를 핀이 있는 칸으로 맞춤)
- 계산 · 동작의 자세한 규칙은 06 맛 지도 기술서

### 상품·로스터리별 페이지
- 원본 자료가 없는 상품·로스터리는 **임시 콘텐츠**로 채우고 "임시" 표시를 단다. 맛 프로필 점수와 로스팅 단계는 맛 노트에서 추정하고, 상세 소개는 소개 문장·맛 노트 카드·추천 추출법·상품 정보로 만든다. 로스터리는 로고 자리 사진, 판매 원두 수·대표 맛·로스팅 경향을 보여주고 위치·인스타그램은 "준비 중". 실제 업체의 수상 경력·주소는 지어내지 않는다
- 상세는 고른 상품 기준으로 이름, 로스터리, 가격, 맛 노트, 이미지, "비슷한 맛의 원두"를 보여준다. 상세 소개 이미지와 맛 프로필이 있는 상품(스프링 블렌드)만 해당 영역을 보여주고, 나머지는 상품 정보 표로 대신한다
- 로스터리 소개는 고른 로스터리 기준. 매장 사진·수상 경력이 있는 곳(커넥츠커피)만 해당 영역을 보여주고, 원두가 없는 로스터리는 "준비 중" 빈 상태

### 캔버스 흐름 보드
- 캔버스 보드는 화면마다 따로 동작하므로, 사이트 전체를 한 보드에 넣은 "흐름 프로토타입" 보드(웹·태블릿·모바일)를 둔다. 이 보드 안에서는 장바구니·검색어·고른 상품이 화면을 넘어가도 유지된다

### 상태 화면
- 불러오는 중(스켈레톤), 결과 없음, 빈 장바구니(예시 상품 담아 보기), 원두 없는 로스터리, 목록 오류(다시 시도), 404, 옵션 품절·수량 최대, 주문할 상품 미선택, 알림 4종. 캔버스 "상태 모음" 보드 기준

### 장바구니 데이터 규칙
- 저장 값은 `{ productId, size, grind, qty }`만. **가격은 저장하지 않고** 상품 데이터와 옵션으로 계산
- localStorage에 저장해 새로고침해도 유지 (Zustand `persist`)
- 같은 상품이라도 옵션이 다르면 다른 줄, 같은 옵션이면 수량만 늘림(최대 20)
- 어느 페이지에서 담아도 헤더 배지와 장바구니 페이지가 같은 데이터를 본다. 배지는 상품 줄 수
- 배송비 2,500원, 선택 상품 합계 30,000원 이상이면 무료

### 가격 규칙 (원본 kokewep 기준)
- 원두 용량: 200g 기본가 / 500g +4,600원 / 1kg +11,000원
- 분쇄: 홀빈, 커피메이커, 에스프레소 머신, 프렌치 프레스, 핸드 드립, 모카포트

### 취향 테스트
- 시작 화면은 맛 지도 그림(「내 취향은 어디?」) + 시작 버튼
- 1–3번 답으로 맛 지도 위 「내 취향」 자리(핀)를 정하고, 핀과 가까운 원두 3개를 추천(거리가 비슷하면 맛 노트가 더 맞는 원두 먼저). 계산은 06 기술서 7장
- 4번에서 디카페인을 고르면 디카페인 원두에서만 고른다
- 5번(추출 도구)은 결과에 영향 없이 분쇄 옵션 안내에만 쓴다
- 결과: 핀이 꽂힌 작은 지도 + 추천 3개 + 「1위 원두 보러 가기」 · 「맛 지도에서 내 자리 보기」 · 「다시 하기」. 핀은 저장돼 목록 지도에도 표시

## 7. 반응형 기준
| 구간 | 폭 | 미리보기 보드 |
|---|---|---|
| 웹 | 1280 이상 (Tailwind `xl`) | 1440 |
| 좁은 웹 | 1024–1279 (`lg`) | — |
| 태블릿 | 641–1023 | 768 |
| 모바일 | 640 이하 (`sm` 미만 포함) | 390 (320까지 깨지지 않음) |

- 화면은 Tailwind 기본 구간 640(`sm`) · 1024(`lg`) · 1280(`xl`)에서 바뀐다. 1024 미만이면 태블릿 배치(헤더 57px · ☰ 메뉴, 필터는 시트), 1280 미만이면 가로 탭에 끝 흐림.
- 높이 560px 이하에서는 헤더 · 목록 도구 줄 · 필터 고정을 푼다.
