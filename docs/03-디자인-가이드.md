# 코케 리뉴얼 — 디자인 가이드 (레이아웃 스펙 포함)

기준: 디자인 캔버스 doc 페이지의 **UI 스타일 가이드** 보드와, 같은 클래스로 만든 프로토타입 전체 페이지. 화면과 이 문서가 다르면 이 문서가 기준이다.

## 0. 문서 안내
- 이 문서는 공용 틀의 **Design Guide + Layout Spec** 을 한 문서에 담는다. Components(토큰 · 규격 · 견본)는 [05 Components](05-Components.md)로 나눴다.
  - 틀의 Guide(화면별 동작) → 이 문서 1 · 8장과 [02-PRD](02-PRD.md) 4장
  - 틀의 Layout Spec → 이 문서 5장
- 보드 이름 대응: 접미 없음 = 웹 라이트(틀의 `D`), `-t` = 태블릿(`DT`), `-m` = 모바일(`DM`). 다크 보드는 없다(다크 모드 미지원).
- 보드 속 글은 크기 · 줄바꿈을 보기 위한 자리 표시이며, 상품 · 로스터리 데이터만 원본 kokewep에서 가져왔다.



## 1. 원칙
1. **맛 지도가 얼굴**: 리뉴얼의 대표 기능은 "맛으로 고르기". 메인 첫 화면과 목록의 지도 보기에서 맛 지도를 가장 크게 보여준다
2. **색은 딥 그린 하나만 강하게**: 주 버튼, 선택 상태, 배지, 현재 메뉴 밑줄은 모두 `primary`. 나머지는 그린을 살짝 섞은 회색
3. **같은 역할은 같은 모양**: 여러 개 고르는 필터는 둥근 칩(채움 + 체크), 하나만 고르는 옵션은 사각 버튼(테두리 강조), 화면 전환은 밑줄 탭, 보기 방식은 세그먼트
4. **줄을 맞춘다**: 모든 페이지가 같은 본문 폭(1280px)을 쓰고, 헤더의 현재 메뉴 밑줄은 헤더 아래 선 위에 겹친다
   - 밑줄은 내비게이션(헤더 현재 메뉴)에만 쓴다. 버튼 · 「전체 보기」 · 원두 이름 링크에는 밑줄 없이 올림 시 색으로 알린다
5. **글자 대비 4.5:1 이상**, 누를 수 있는 곳은 최소 24px, 기본 44px (값은 [05](05-Components.md))

## 3. 레이아웃 스펙
- 컨테이너(`.k2-wrap`): `max-width: 1280px`, 좌우 여백 PC 40px / 태블릿 24px / 모바일 16px. 헤더, 본문, 푸터가 모두 같은 컨테이너를 써서 왼쪽 줄이 맞는다
- 브레이크포인트: `sm ≤ 640px`(모바일), `lg` 미만 ≤ 1023px(태블릿), 1024–1279 좁은 웹, 그 이상 PC

## 4. 오버레이 · 화면 요소
컴포넌트 하나하나의 모양 · 크기는 [05 Components](05-Components.md). 여기는 화면에서의 위치와 동작.

- 헤더 검색 트리거: 홈에서만 헤더 가운데에 입력창 모양 버튼(480 × 44px, 안내 글자 `muted`, 오른쪽 돋보기). 다른 페이지와 1023px 이하는 장바구니 왼쪽 44px 돋보기 아이콘 버튼. 둘 다 누르면 검색 레이어가 열림
- 검색 레이어: 화면 위에서 내려오는 흰 패널 + 아래 어두운 배경 50%. 입력 칸 52px(18px 글자, 왼쪽 돋보기, 입력 중 오른쪽 24px 원형 지우기 버튼) + 오른쪽 52×52 X 닫기 버튼(테두리 `line`, 모서리 8px). 버튼과 입력 칸 높이는 항상 같게 맞춘다. 아래 2단: 왼쪽 최근 검색어(칩 테두리 안에 글자 + 28px 원형 X, 전체 삭제)·추천 검색어 칩, 오른쪽 많이 찾는 원두 또는 미리 보기 결과(사진 52px + 로스터리·이름·맛·가격) + "모두 보기" 주 버튼. 1023px 이하는 전체 화면, 1단
- 목록 검색창: 목록 도구 줄 첫 줄 전체 폭, 44px, 왼쪽 돋보기
- 카페인 필터: 필터 맨 위 "카페인" 그룹, "디카페인" 필터 칩 하나(켜면 적용한 조건 칩에도 표시)
- 모달: 폭 440px(모바일은 화면 폭 - 40px), 위에서 140px(모바일 96px), 모서리 12px, 어두운 배경 50%. X, ESC, 바깥 클릭으로 닫힘 (현재 화면에서는 쓰지 않음, 공통 규격으로만 둠)
- 바텀 시트(모바일 필터): 화면 아래에 붙고 최대 높이 80%, 위 모서리 16px, 머리 56px(제목 + 닫기), 아래 고정 버튼 줄(초기화 1 : 결과 보기 2)
- 오류: 테두리 박스 + 아이콘 + 제목 + 해결 방법 한 줄 + "다시 시도" 주 버튼
- 404: 큰 숫자 64px `primary`, 제목 28px, 홈(보조)·모든커피(주) 버튼
- 알림(토스트): 화면 아래 가운데. 시간 · 멈춤 규칙은 05 「팝오버 · 메뉴 · 알림」

### 푸터
- `footer-bg` 바탕, 위 1px 선. 왼쪽 고객센터(번호 26px 강조, 운영 시간, 이메일), 오른쪽 지원 메뉴(링크 없는 글자)

- 아이콘: 24px 그리드의 선 아이콘(lucide 계열). 장식 아이콘은 `aria-hidden`, 아이콘만 있는 버튼은 `aria-label`
- 상품 사진: 4:5(목록 카드) / 1:1(메인·상세·추천), `object-fit: contain`, 안쪽 여백 8%
- 이미지 포맷: WebP, `next/image`로 크기별 제공
