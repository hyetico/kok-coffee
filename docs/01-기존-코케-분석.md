# 코케 리뉴얼 — 기존 버전 분석

## 서비스 콘셉트
- 여러 로스터리의 원두를 한곳에서 고르고 **내 입맛에 맞춰 구독**하는 커피 큐레이션 쇼핑몰
- 핵심 키워드: 취향(맛 노트 `고소 & 묵직한` 등), 취향 테스트, 구독, 로스터리

## 버전 히스토리
| 버전 | 시기 | 스택 | 페이지 |
|---|---|---|---|
| kokewep | 2022.07 | HTML / CSS / jQuery, GSAP, Swiper, ScrollMagic, YTPlayer | 메인, 서브(목록), 상세 |
| kokereact | 2022.08 | CRA, React 18, Redux Toolkit, React Router, Bootstrap + Semantic UI + styled-components | 메인, 모든커피, 싱글오리진, 로스터리, 브랜드, 상세, 장바구니, 스토어 |
| **리뉴얼 (이번)** | 2026 | Next.js(App Router), TypeScript, Tailwind CSS, Zustand | 메인, 목록, 상세, 장바구니 |

## 기존 메인 구성 (kokewep/index.html)
1. 상단 띠배너: 구독 시작하면 3,000원 즉시 할인 · 무료교환 · 무료배송
2. 헤더: 검색, 장바구니, 전체메뉴(모든커피/브랜드/싱글오리진/블랜드/취향테스트/구독)
3. 메인 비주얼 3장: "이번커피도, 다음커피도" / "코케를 구독 중인" / "한 번쯤 마셔보고 싶었던"
4. BEST (맛 노트 탭 필터) → NEW → 추천 배너(30초만에 커피 추천받기) → 2022 HOT 로스터리 → 로스터리 → 컬렉터 배너 → 리뷰 → 푸터

## 데이터 (kokereact/src/components/data.jsx)
- 상품: `id, dataStatus(블렌드/싱글오리진/single 혼용), logo, image, desc(맛 노트), title('[로스터리] 상품명'), price(문자열), pricevalue(숫자)`
- 로스터리 목록 별도
- 상세 옵션(HTML 버전): 원두용량 200g / 500g(+4,600원) / 1kg(+11,000원), 분쇄선택(홀빈·에스프레소·프렌치프레스·핸드드립·모카포트)

## 개선 포인트 (= 포트폴리오에 쓸 전후 비교)
### 퍼블리싱
- [ ] **반응형 없음** — 모든 CSS에 `@media`가 0개
- [ ] **이미지 대체텍스트** — 메인에 `alt=""` 9개, 의미 있는 이미지도 비어 있음
- [ ] 제목 구조 — h2가 섹션 제목·팝업·숫자에 섞여 쓰임 (`<h2 id="number">0`)
- [ ] 무거운 외부 의존 — jQuery + GSAP + ScrollMagic + Swiper + YTPlayer를 CDN으로 9개 로드
- [ ] 팝업·메뉴 키보드 접근성(포커스 이동, Esc 닫기) 없음
- [ ] 파일 정리 — `연습.html`, 한글/공백 섞인 이미지 파일명

### React 버전 코드
- [ ] UI 라이브러리 3개 혼용 (Bootstrap, Semantic UI, styled-components) → Tailwind 하나로 통일
- [ ] 데이터 불일치 — `dataStatus` 값이 '블렌드/싱글오리진/single'로 제각각, 가격이 문자열+숫자 중복
- [ ] 로고 클릭을 `onClick + navigate`로 처리 → `<Link>`로 (링크 의미, 새 탭 열기 가능)
- [ ] CRA(react-scripts 2.x) — 지원 종료된 빌드 도구

## 원본 메뉴 구조
- kokewep: 실제 페이지는 메인·목록·상세. 브랜드(로스터리 30여 곳 드롭다운), 싱글오리진, 블랜드, 취향테스트, 구독하기, 전체메뉴(구독후기·커뮤니티·고객센터)는 모두 `#` 링크
- kokereact: 모든커피, 로스터리(로고 16곳), 브랜드(커넥츠커피 소개), 상세, 장바구니 페이지가 실제로 있음

## 리뉴얼에서 뺀 것
| 원본 기능 | 이유 |
|---|---|
| 정기 구독, 구독 할인, 배송 주기 | 결제·회원 기능 없이는 동작할 수 없어 범위에서 제외. 띠배너·메인 배너·상품 태그·상세·장바구니에서 모두 삭제 |
| 구독 후기, 리뷰 | 실제 후기 데이터가 없어 삭제 (메인 리뷰 섹션, 상세 리뷰·문의 탭) |
| 전체메뉴(커뮤니티, 고객센터 등) | 연결할 페이지가 없음 |
